The batterie-de-savoir repo serves a dual role: it's both the marketplace (listing all plugins) and itself a plugin (hosting cross-cutting commands like /batterie-update). This is achieved with `"source": "./"` in marketplace.json — the same pattern Anthropic's official marketplace uses for bundled plugins. The trailing slash matters: `"."` fails schema validation.

For CLI-bearing plugins (bon, garde-manger, passe, todoist-gtd), the version lives in one place only: `.claude-plugin/plugin.json`. The pyproject.toml reads it dynamically via hatchling's `[tool.hatch.version]` with a regex pattern matching the JSON. This eliminates the dual-maintenance problem where plugin versions and CLI versions drift apart. The pattern was applied to all four plugins in March 2026.

The `claude plugin update` command checks versions against a cached marketplace index. If the marketplace itself has been updated (new plugin versions pushed), you must run `claude plugin marketplace update` first — otherwise `plugin update` reports everything as current. This is why /batterie-update's first step is always a marketplace refresh.
