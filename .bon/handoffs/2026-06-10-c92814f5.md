## For Claudes to come

Claude Desktop and the Claude Code CLI share `~/.claude/plugins/` state files (installed_plugins.json, known_marketplaces.json), and Desktop bulk-rewrites them while running — single-timestamp writes that can zero out CLI-installed plugin entries within minutes while leaving cache directories intact. This is the signature of the May "lost registry entries" mystery (bds-wezubo), observed live twice tonight on the Mac. Practical rules: quit Desktop before CLI plugin surgery on a machine that runs both; verify registry writes stuck by sampling the file twice across an interval, not once; and treat registry-without-cache or cache-without-registry asymmetries as Desktop's fingerprint. Separately, the cutover taught a retirement discipline: before deleting any artifact, grep the estate for its READERS — the bajibo brief said "remove marketplace.json" and the daily bot's lint script read exactly that file for its plugin list; the deletion would have shipped green and turned every subsequent bot run red. The fix (reading the list from the new marketplace's sibling checkout) worked because CI and local checkouts deliberately share the same directory layout — a property worth preserving when adding pipeline scripts.
