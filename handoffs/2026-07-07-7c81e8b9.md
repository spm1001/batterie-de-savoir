## For Claudes to come

**When a pipeline needs a variant of an artifact, derive it from the pipeline's own guarded output, not from source.** mise-home is built by transforming the *just-vendored public mise* — after the husk/parity guards, the ratchet, and the version stamp have already run — so the variant inherits every guarantee by construction: identical runtime bytes, identical version, even identical quarantine state on a bad day. The alternative (a parallel vendor-from-source path) would have needed every guard duplicated and would drift the day one copy was edited. Generalises to any public/private, prod/staging, or white-label artifact split: transform downstream of the guards, and add one loud grep-guard for the strings the transform must rewrite (leftover-identity = build failure). Repo-specific detail is in understanding.md ("Shared plumbing — AS-BUILT"); the pattern travels.
